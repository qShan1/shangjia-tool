# 使用指南

## 基本流程

1. 打开管理台并完成本地管理员登录。
2. 在账号管理中添加账号，按页面要求保存 Cookie 或完成扫码登录。
3. 在回复设置中配置关键词、默认回复或 AI 回复。
4. 按需配置商品、订单和发货规则。
5. 在账号状态和日志页面观察本地运行状态。

## 账号与验证

Cookie、Token 和浏览器画像都是本地敏感运行数据。需要验证时，按照管理台展示的信息在官方客户端人工完成；不要反复自动刷新或试图绕过滑块、人脸等平台验证。

网页端已登录不代表管理台接口可用。账号状态、订单和消息数据以管理台实际接口响应为准。

## 自动化边界

在启用自动回复、自动发货或商品操作前，先确认规则、商品映射和账号状态。对外发送、发货和平台操作具有业务影响，应先在少量数据上验证，再扩大范围。
