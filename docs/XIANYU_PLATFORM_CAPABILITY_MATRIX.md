## 判定口径

- **已真实验证**：有真实闲鱼账号和平台侧结果证据；本地 HTTP 200、SQLite 写入、日志、单元测试均不单独算作平台成功。
- **代码存在，当前待验证**：能追踪到闲鱼 WebSocket、MTOP 或网页会话调用，但本轮没有当前账号的平台侧结果。
- **本地能力**：只操作本项目的 SQLite、配置、缓存、日志、页面或任务编排。
- **外部能力**：调用闲鱼以外的 AI、通知、卡券或 Webhook 服务。
- **人工验证**：二维码扫码、滑块、短信、刷脸、平台审核或风控恢复需要人工参与。
- **未实现**：当前仓库没有对应的闲鱼上游调用；不得用相近的本地按钮代替。

## 明确未实现或不得混称的平台能力

1. 编辑现有闲鱼在售商品标题、描述、价格、图片：当前 `PUT /items/{cookie_id}/{item_id}` 仅更新 SQLite `item_info.item_detail`。
2. 删除/下架闲鱼在售商品：当前商品删除路由只删除本地 `item_info` 记录。
3. 删除闲鱼平台订单：当前订单删除路由只删除本地订单记录。
4. 写入闲鱼平台黑名单：当前个人黑名单是本系统处理规则。
5. 闲鱼原生数字商品卡券/自动交付：当前实现是本地卡券和规则，经聊天发送，再独立尝试平台发货确认。
6. 通过本系统解除滑块、短信、刷脸、审核或账号风控：日志和诊断只能观测，不能代表解除。
